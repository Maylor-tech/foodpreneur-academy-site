# FoodPreneur Academy Website

A professional learning platform designed specifically for independent restaurant owners and managers. This static website serves as the initial landing page and information hub for FoodPreneur Academy.

🌐 **[Visit the Live Site](https://maylor-tech.github.io/foodpreneur-academy-site/)**

## 🎯 Project Overview

FoodPreneur Academy is an online learning platform that helps restaurant owners:
- Optimize their operations
- Increase profitability
- Improve team management
- Master restaurant marketing
- Scale their business effectively

## 🚀 Features

- Responsive, mobile-first design
- Modern UI/UX focused on busy restaurant professionals
- Easy-to-navigate course catalog
- Lead capture forms
- Business calculator tools
- Resource library
- Blog section

## 💻 Tech Stack

- HTML5 (Semantic markup)
- CSS3 (Modern CSS with Flexbox/Grid)
- JavaScript (ES6+)
- Responsive Design
- Performance Optimized

## 🛠️ Local Development

1. Clone the repository:
```bash
git clone https://github.com/Maylor-tech/foodpreneur-academy-site.git
```

2. Navigate to the project directory:
```bash
cd foodpreneur-academy-site
```

3. Open index.html in your browser or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js
npx serve
```

4. Visit `http://localhost:8000` in your browser

## 📱 Responsive Design

The site is fully responsive and tested across:
- Mobile devices (320px and up)
- Tablets (768px and up)
- Desktops (1024px and up)
- Large screens (1440px and up)
