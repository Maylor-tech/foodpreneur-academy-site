## Project Overview

FoodPreneur Academy is a static informational website designed to introduce an online learning platform for independent restaurant owners. The site serves as the initial phase of a larger educational platform, focusing on lead generation and course previews.

### Target Audience

- Independent restaurant owners and managers
- Food service entrepreneurs
- Restaurant industry professionals

### Core Technologies

- HTML5 (Semantic markup)
- CSS3 (Modern layouts with Flexbox/Grid)
- Vanilla JavaScript (ES6+)
- Static site architecture

### Development Status

Current Phase: Static Informational Site
Future Plans: Integration with LMS platform (Kajabi/Podia)
