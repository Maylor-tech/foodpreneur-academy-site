FoodPreneur Academy - Test Script

1. Navigation Testing

Desktop Navigation

  • Verify all main navigation links are present and correctly labeled
  • Check that active page is highlighted in navigation
  • Test hover states on navigation items
  • Verify logo links to homepage

Mobile Navigation

  • Test hamburger menu appears at mobile breakpoint
  • Verify menu opens and closes properly
  • Check all links are accessible in mobile menu
  • Test menu closes after link selection

Footer Navigation

  • Verify all footer links are present and working
  • Test social media links open in new tab
  • Check contact information is correct

2. Form Testing

Contact Form

  • Test form validation for required fields
  • Verify email format validation
  • Test form submission and success message
  • Check error messages for invalid inputs

Sign-in Form

  • Test email and password validation
  • Verify "Remember Me" functionality
  • Test "Forgot Password" link
  • Check error messages for invalid credentials

Newsletter Subscription

  • Test email validation
  • Verify subscription success message
  • Check duplicate email handling

3. Interactive Elements

Course Filtering

  • Test category filter buttons
  • Verify course cards update correctly
  • Check "All" filter resets selection
  • Test multiple filter combinations

Pricing Toggle

  • Test monthly/annual toggle switch
  • Verify price updates correctly
  • Check "Save X%" badge appears for annual
  • Test "Best Value" badge positioning

FAQ Accordions

  • Test accordion open/close functionality
  • Verify only one section opens at a time
  • Check smooth animation transitions

Resource Downloads

  • Test download button functionality
  • Verify file size displays correctly
  • Check file type icons

4. Responsive Design

Breakpoint Testing

  • Test mobile view (320px - 480px)
  • Test tablet view (481px - 768px)
  • Test small desktop (769px - 1024px)
  • Test large desktop (1025px+)

Layout Elements

  • Verify grid layouts adjust correctly
  • Test image scaling and aspect ratios
  • Check text wrapping and readability
  • Verify spacing remains consistent

Mobile-Specific Features

  • Test touch targets (minimum 44px)
  • Verify no horizontal scrolling
  • Check font sizes remain readable

5. Accessibility Testing

Keyboard Navigation

  • Test tab order is logical
  • Verify focus states are visible
  • Check skip links work properly
  • Test all interactive elements are keyboard accessible

Screen Reader Compatibility

  • Verify all images have alt text
  • Test ARIA labels and roles
  • Check form labels are properly associated
  • Verify heading hierarchy is logical

Color and Contrast

  • Test text contrast meets WCAG 2.1 AA standards
  • Verify color is not the only means of conveying information
  • Check focus states have sufficient contrast

6. Browser Compatibility

Modern Browsers

  • Test in Chrome (latest version)
  • Test in Firefox (latest version)
  • Test in Safari (latest version)
  • Test in Edge (latest version)

Mobile Browsers

  • Test in Chrome for Android
  • Test in Safari for iOS
  • Test in Firefox for Android

7. Performance Testing

Page Load

  • Test initial page load time
  • Verify images are optimized
  • Check CSS and JavaScript minification
  • Test caching headers

Resource Usage

  • Monitor memory usage
  • Check CPU utilization
  • Test with multiple tabs open
